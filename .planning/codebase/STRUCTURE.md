## Directory Purposes

**src/components/ui/**
- Purpose: House all Material Design 3 component implementations
- Contains: 25+ React components with CVA-driven styling
- Key files: `button.tsx`, `text-field.tsx`, `navigation-bar.tsx`, `dialog.tsx`, `menu.tsx`, `snackbar.tsx`
- Patterns: All export component + variants, use forwardRef, extend native HTML props

**src/lib/**
- Purpose: Share utility functions across components
- Contains: Single utility function `cn()` for class merging
- Key files: `utils.ts` (clsx + tailwind-merge wrapper)

**src/styles/**
- Purpose: Define global theme and animations
- Contains: Theme colors via Tailwind @theme, keyframe animations, shape morphing rules
- Key files: `globals.css` (1-350 lines covering M3 color system, animations, data-attribute selectors)

**src/index.tsx**
- Purpose: Public API surface for library consumers
- Contains: Re-exports of all components, types, and utilities
- Pattern: Import globals.css once to activate theme, export both components and variants

**stories/**
- Purpose: Document components with interactive examples in Storybook
- Contains: Story files for each component using Meta/StoryObj pattern
- Naming: `[ComponentName].stories.tsx`
- Pattern: Use library components in stories (not native HTML), render functions for stateful demos

**tests/**
- Purpose: Unit test components with @rstest/core and @testing-library/react
- Contains: Test files parallel to source components
- Naming: `[component-name].test.tsx`
- Pattern: Use render + screen queries, test variants, accessibility, event handlers

**dist/**
- Purpose: Bundled output for npm distribution
- Generated by: `bun run build` (Rslib)
- Format: Unbundled ESM with TypeScript definitions (.d.ts files)
- Export: package.json exports point to dist/index.js and dist/index.d.ts

**docs/**
- Purpose: Generated documentation site
- Built by: Rspress dev/build commands
- Framework: Rspress (React-based documentation)

**.storybook/**
- Purpose: Storybook configuration and setup
- Key files: `main.ts` (stories glob, addons config), `preview.ts` (global decorators/parameters)

**.planning/codebase/**
- Purpose: GSD (Get Stuff Done) codebase analysis and documentation
- Contains: ARCHITECTURE.md, STRUCTURE.md, CONVENTIONS.md, TESTING.md, CONCERNS.md
- Used by: /gsd:plan-phase and /gsd:execute-phase commands

## Naming Conventions

**Files:**
- Component files: kebab-case (e.g., `button.tsx`, `text-field.tsx`, `navigation-bar.tsx`)
- Story files: PascalCase (e.g., `Button.stories.tsx`, `TextField.stories.tsx`)
- Test files: kebab-case + `.test.tsx` suffix (e.g., `button.test.tsx`)
- Style files: `globals.css` for global styles

**Directories:**
- Components container: `ui/` (all components in single directory)
- Utility container: `lib/` (utilities exported as single module)
- Style container: `styles/` (theme and animations)

**Component Exports:**
- Component: PascalCase (e.g., `Button`, `TextField`, `NavigationBar`)
- Variants object: camelCase + `Variants` suffix (e.g., `buttonVariants`, `textFieldVariants`)
- Props type: PascalCase + `Props` suffix (e.g., `ButtonProps`, `TextFieldProps`)
- Context: PascalCase + `Context` suffix (e.g., `NavigationBarContext`)
- Context hook: camelCase + `use` prefix (e.g., `useNavigationBar`, `useMenu`)

**CSS Classes (Tailwind):**
- All classes are lowercase Tailwind utilities
- Data attributes for state: `data-focused`, `data-error`, `data-populated`, `data-selected`, `data-connected-group`, `data-menu-group`
- Color tokens: `bg-primary`, `text-foreground`, `border-outline`
- Custom variables: `--color-primary`, `--spacing-4_5`, `--square-radius`

## Where to Add New Code

**New Component:**
1. Create `src/components/ui/[component-name].tsx`
2. Import CVA, React, cn, Ripple (if interactive)
3. Define `[component]Variants` via cva()
4. Define `[Component]Props` type extending native element + custom props
5. Implement component with React.forwardRef
6. Export both component and variants: `export { Component, componentVariants }`
7. Add export to `src/index.tsx` in appropriate section (Components or Utilities)
8. Create `stories/[ComponentName].stories.tsx` with Meta/StoryObj pattern
9. Create `tests/[component-name].test.tsx` with @rstest/core + @testing-library/react

**New Theme Color/Animation:**
1. Add to `src/styles/globals.css` in @theme block (colors) or as @keyframes (animations)
2. Reference in components via Tailwind class utilities
3. No component code changes needed — CSS custom properties are theme-scoped

**New Utility Function:**
1. Add to `src/lib/utils.ts`
2. Export from there
3. Add export to `src/index.tsx` in Utilities section
4. Use in components via relative import

**Modifying Existing Component:**
1. Edit `src/components/ui/[component-name].tsx`
2. Update variants in CVA if visual changes
3. Update props type if new props added
4. Update story file `stories/[ComponentName].stories.tsx` to showcase new variants/props
5. Add/update tests in `tests/[component-name].test.tsx`
6. Run `bun run build` to verify TypeScript, then `bun run storybook` to verify visually

## Build Output Structure

After `bun run build`, dist/ contains:

```
dist/
├── index.d.ts                     # Type definitions entry
├── index.js                       # JavaScript entry (unbundled)
├── styles/
│   └── globals.css                # Theme styles
└── src/
    ├── components/
    │   └── ui/
    │       ├── button.d.ts
    │       ├── button.js
    │       ├── [other components as .d.ts and .js]
    ├── lib/
    │   ├── utils.d.ts
    │   └── utils.js
    └── styles/
        └── globals.css
```

Package.json exports are configured as:
- `.` → `dist/index.js` (main entry)
- `./styles.css` → `dist/styles/globals.css` (separate styles import)
