import { Badge } from 'm3you';

A badge marks an element as having new or unread content. `BadgeAnchor` takes
care of the positioning — wrap the element and pass the badge to it.

A dot badge (no `count`) means "something new"; a numeric badge means "this many
things". `max` caps the displayed number and adds a `+`.

<Playground
  name="Badge"
  controls={{
    count: { min: 0, max: 150, default: 8 },
    max: { min: 9, max: 999, step: 90, default: 99 },
    color: ['error', 'primary', 'secondary', 'tertiary'],
    visible: true,
  }}
  render={(props) => <Badge {...props} />}
/>
