---
title: Tooltip
description: Plain and rich tooltips that explain an element on hover.
---

Plain tooltips name an element in a few words. Rich tooltips add a headline, a
paragraph and up to one action — use them for genuinely new concepts, not for
labels.

Both need a `TooltipProvider` above them, which shares the open/close delays so
moving between neighbouring triggers does not re-trigger the delay each time.
