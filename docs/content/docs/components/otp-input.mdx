import { OTPInput } from 'm3you';

OTP inputs collect short numeric verification codes. The code appears in
separate slots, while a single native input preserves keyboard navigation,
paste, password-manager and one-time-code autofill behavior.

The input accepts digits only by default. `onValueChange` gives you the whole
code as a string, and `onComplete` runs when every slot is filled.
