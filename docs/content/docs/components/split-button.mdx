---
title: Split button
description: A primary action beside a menu of related ones.
---

A split button pairs one obvious action with a menu of variations on it. Compose
it from `SplitButtonAction` for the leading half and `SplitButtonMenu` for the
trailing chevron; both inherit `variant`, `size` and `shape` from the root.
