When the action needs naming, the extended FAB adds a label. `label` is a
required prop rather than children, so the component can measure and animate its
own width.

<Playground
  name="ExtendedFAB"
  controls={{
    label: 'Create',
    variant: ['tonal', 'filled', 'elevated', 'outlined', 'text'],
    size: ['md', 'sm', 'lg'],
    lowered: false,
    disabled: false,
  }}
  render={(props) => <ExtendedFAB {...props} icon={<Plus size={20} aria-hidden="true" />} />}
/>

## Sizes

`fabSize` picks one of the three kit sizes: small (56dp), medium (80dp) and large
(96dp). Each size sets its own padding, corner radius, icon size and type scale.
The older `size` prop still works. `md`, the default, renders the same as small,
and `lg` renders the same as large. Every size and variant rests at elevation
level 3, rises to level 4 on hover and drops back to level 3 while pressed.
`lowered` moves those levels down to 1, 2 and 1.

## Shape

The corners follow the size: 16dp on the small extended FAB, 20dp on the medium
and 28dp on the large. The legacy `xs`, `sm` and `md` sizes take 16dp and `lg`
takes 28dp. An extended FAB keeps its corner radius when pressed. Unlike a
button it does not morph by default; pass `morph` to opt in.
