title: Standard button group
description: Evenly spaced buttons that share size, shape and selection.
---

Button groups hand their `size`, `shape` and `morph` down to every `Button`
inside them through context, so you set those once on the group.

Selection is by **index**, not by value: `value` and `defaultValue` are arrays of
positions, and `onValueChange` receives the new array.

## Multiple selection

With `selectionMode="multiple"`, any number of buttons can be selected at once —
the pattern for text formatting and filter toolbars.
