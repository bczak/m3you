import { TextField } from 'm3you';

Text fields collect typed input. Both variants animate the label into the field
outline on focus. Use `type="textarea"` for multiline input and control its
initial height with `rows`. Use `supportingText` for guidance that is always
relevant, and `errorText` for a message that replaces it when `error` is set.

`onValueChange` gives you the string directly, so you rarely need to reach into
the event.

## Multiline

```tsx
<TextField
  type="textarea"
  variant="outlined"
  rows={4}
  label="Notes"
  maxCharCount={500}
/>
```
