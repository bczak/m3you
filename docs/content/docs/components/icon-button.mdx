import { Star } from 'lucide-react';
import { IconButton } from 'm3you';

Icon buttons carry a single action in the space of an icon. They share the
Button size and shape scales, and add a `width` axis for tighter or roomier
targets.

Every icon button needs an `aria-label` — there is no visible text to name it.

## Shape and morph

Round is the default; square gives a more structural feel. While pressed, every
icon button tightens its corners to a smaller radius — 8dp at `xs` and `sm`,
12dp at `md`, 16dp at `lg` and `xl` — and springs back on release. This is on by
default; pass `morph={false}` to keep the corners still. Inside a button group,
the group's own `morph` applies unless the button sets one.

## Width

`width` changes horizontal padding without changing height, so a row of icon
buttons stays on one baseline while individual targets grow.
