import { Star } from 'lucide-react';

The icon-only counterpart to the toggle button — favouriting, muting, pinning.
Give it an `aria-label` that names the setting, not the action.

<Playground
  name="ToggleIconButton"
  controls={{
    variant: ['standard', 'filled', 'tonal', 'elevated', 'outlined'],
    size: ['sm', 'xs', 'md', 'lg', 'xl'],
    width: ['default', 'narrow', 'wide'],
    shape: ['round', 'square'],
    defaultSelected: false,
    disabled: false,
  }}
  render={(props) => (
    <ToggleIconButton {...props} aria-label="Star">
      <Star size={20} aria-hidden="true" />
    </ToggleIconButton>
  )}
/>

## Colour

`color` swaps the M3 role family. A `standard` toggle has no container or
outline, so the colour marks the selected state only: unselected, it keeps the
neutral on-surface-variant icon, and selecting it brings the colour in.
Otherwise a coloured standard toggle would look the same either way. An
`outlined` toggle keeps the colour-role icon inside its outline when unselected
(as an outlined `Button` does), and selecting it fills a colour-role container.
