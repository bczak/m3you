import { LoadingIndicator } from 'm3you';

The Material 3 Expressive loading indicator cycles through seven shapes,
morphing between them rather than cutting. Each shape is resampled to the same
number of points so `clip-path: polygon()` can interpolate between them, and
point zero of every shape is aligned so the animation does not swirl.

The shapes are exported as `SHAPE_POLYGONS` if you want to use them elsewhere —
this site's logo and hero are clipped from them.

### Custom size

For a size off the scale, set a `width` through `style` (a class has to
outrank the `.md-loading-indicator[data-size]` rule). The height follows it,
and the shape stays at the kit's 38/48 of the container, so a 96px indicator
draws a 76px shape. The indicator keeps its circle even in a flex or grid row
that would otherwise stretch it to a taller sibling.

## Contained

The contained variant sits on a filled surface, for use over content.

## Colour

The indicator uses the primary role, or on-primary-container when contained
(the container itself is primary-container). Pass `color` (any CSS colour or
token, such as `var(--md-sys-color-tertiary)`) to change it. It combines with
a `style` you pass, so a custom width and a custom colour can be used together.
If `style` also sets `--md-loading-indicator-color`, the `color` prop wins.
