import { Slider } from 'm3you';

Sliders suit values where the exact number matters less than the relative
position — volume, brightness, opacity. Setting `step` turns the slider discrete
and draws stop indicators along the track.

Use `mode="centered"` for values that diverge from an origin, or `RangeSlider`
when the user needs to choose a lower and upper bound.
