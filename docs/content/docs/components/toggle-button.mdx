import { ToggleButton } from 'm3you';

A toggle button represents a setting that is on or off, rather than an action
that happens once. Use `selected` with `onSelectedChange` to control it, or
`defaultSelected` to let it manage itself.

## Morph

With `morph`, the corner radius changes while the button is held — the
Expressive press gesture. It runs on the spring curve, so it settles rather than
snapping.
