---

Menus present a list of choices on a temporary surface. They are built on Base
UI's menu primitive, so keyboard navigation, typeahead and focus return work
without any wiring.

`MenuTrigger` takes a `render` prop to use your own button as the trigger, the
same convention as Dialog, Tooltip and the sheets. (`asChild` still works but is
deprecated.)
