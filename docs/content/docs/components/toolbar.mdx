title: Toolbar
description: A floating or docked bar of related actions.
---

import { IconButton, Toolbar } from 'm3you';
import { Bold, Italic, Underline } from 'lucide-react';

Toolbars gather actions that apply to the current view. `floating` toolbars hover
above content with a shadow; `docked` toolbars sit flush against an edge.

## Examples

<Example name="toolbar/basic" title="A floating text toolbar" />

A floating toolbar lays its actions into 48px slots, 4px apart, with 8px of
padding at the ends and 12px across. A 40px icon button sits 4px inside its
slot, so 12px shows between icons and around them, and three icon buttons make
a 168 × 64 pill. A text button fills its slot's width, so it sits 8px from the
ends and 4px from another text button. `gap` and `padding` set the slot gap
and the container padding.
